# 紫微斗数 · 安装教程

适用于 **Mac（Apple 芯片，macOS 12 及以上）** 和 **Windows 10 / 11（64 位）**。

> [!NOTE]
> 本软件未购买苹果和微软的开发者签名，首次打开时系统会提示拦截，按下面步骤放行一次即可，之后直接双击打开。

## Mac 安装

请先确认电脑为 **Apple 芯片**：点击屏幕左上角苹果图标 › **关于本机**，「芯片」一栏为 `Apple M1` / `M2` / `M3` / `M4` 等即可。**Intel 芯片的 Mac 不支持桌面安装包**，请参考 README 中的「从源码运行（本机网页版）」。

1. **安装应用**  
   双击下载的 `ziwei-x.y.z-mac-arm64.dmg`（例如 `ziwei-0.1.0-mac-arm64.dmg`），在弹出的窗口中将「紫微斗数」图标拖入 `Applications`（应用程序）文件夹。

2. **首次打开放行**  
   在「启动台」或「访达 › 应用程序」中双击「紫微斗数」。系统会提示无法验证开发者，请按系统版本操作：

   - **macOS 15（Sequoia）及以上**
     1. 弹窗提示“无法验证‘紫微斗数’是否包含可能危害 Mac 安全或泄漏隐私的恶意软件”时，点击 **「完成」**（不要点移到废纸篓）。
     2. 打开 **「系统设置 › 隐私与安全性」**，向下滚动到「安全性」区域，点击 **「仍要打开」**。
     3. 在再次弹出的确认框中点击 **「仍要打开」**，输入开机密码或验证指纹即可启动。

   - **macOS 12 – 14**
     1. 在「应用程序」中按住 `Control` 键点按「紫微斗数」（或双指轻点触控板），选择 **「打开」**。
     2. 在弹出的确认窗口中再次点击 **「打开」**。

3. **钥匙串访问提示**  
   保存 AI 设置或更新版本后，若弹出“紫微斗数想要使用钥匙串中的‘紫微斗数 Safe Storage’”，输入开机密码并选择 **「始终允许」**（用于加密读写你保存的 API Key）。

> [!TIP]
> **提示「已损坏，无法打开」？**  
> 这通常是下载工具或聊天软件传输时为文件加上了隔离标记。打开「终端」（启动台 › 其他 › 终端），执行以下命令后再重新打开应用：
> ```bash
> xattr -dr com.apple.quarantine /Applications/紫微斗数.app
> ```

## Windows 安装

1. **浏览器下载提示**  
   若浏览器提示“通常不会下载此文件”或“可能有害”，点击下载条目旁的 `…` 或下拉箭头，选择 **「保留」** › **「仍然保留」**。

2. **运行安装程序**  
   双击 `ziwei-x.y.z-win-x64-setup.exe`（例如 `ziwei-0.1.0-win-x64-setup.exe`）。若出现蓝色的 **「Windows 已保护你的电脑」（SmartScreen）** 提示：
   1. 点击左下方的 **「更多信息」**。
   2. 点击出现的 **「仍要运行」** 按钮。

3. **完成安装**  
   选择安装目录（保持默认即可），点击「安装」直至完成，桌面和开始菜单会生成「紫微斗数」快捷方式。

4. **杀毒软件误报处理**  
   360、火绒、电脑管家等安全软件若拦截未签名程序，请选择 **「信任」** 或 **「允许运行」**，必要时将安装目录加入信任列表。

## 第一次使用

1. **配置 AI 服务（可选）**  
   首次启动会进入设置引导页：选择 AI 服务商（推荐 **DeepSeek**），粘贴你的 API Key，点击「测试连接」通过后保存即可。也可以先点 **「先跳过，只排盘」**，之后随时在顶栏「设置」中补充。
   - **DeepSeek**：前往 [platform.deepseek.com](https://platform.deepseek.com) 注册并充值，在「API keys」中创建 Key。
   - **硅基流动**：前往 [cloud.siliconflow.cn](https://cloud.siliconflow.cn) 注册，在「API 密钥」中创建 Key。  
   *(AI 费用由你直接向服务商按实际用量结算，软件本身全部功能免费；软件内设置页也附有详细指引。)*

2. **书库说明**  
   AI 解读默认检索安装包内置书库（27 本参考书）。如需使用自己的书籍，可在「古籍库」页面的「书库」标签下新建书库、导入 PDF，并勾选启用。

3. **开始排盘**  
   在首页填写出生日期、时间与性别即可排盘；软件顶栏「帮助」页还提供了导入书、数据备份、升级与卸载等说明。

## 遇到问题

- **一直卡在「正在启动」或提示「本地服务启动失败」**  
  点击界面上的 **「重试」**；若仍失败，点击 **「打开日志」**，并在提交 [GitHub Issue](https://github.com/LMAYRY/ziwei-doushu-desktop/issues) 时附上日志内容。
- **AI 解读提示 Key 错误、余额不足或网络异常**  
  请核对 API Key 是否复制完整、服务商账户是否有可用额度，以及当前网络能否正常访问对应服务商接口。
- **卸载软件**  
  Mac 将「应用程序」中的「紫微斗数」拖入废纸篓即可；Windows 前往「设置 › 应用」卸载。命盘与本地数据会保留在本机，重装后依然可用。
