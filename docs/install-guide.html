紫微斗数 安装教程

适用于 Mac（Apple 芯片，macOS 12 及以上）和 Windows 10 / 11（64 位）。

Mac 安装

先确认电脑是 Apple 芯片：点左上角苹果图标 › 关于本机，「芯片」一栏写着 Apple M1、M2、M3、M4 等即可。Intel 芯片的 Mac 不能使用。

  1. 安装：双击下载的 ziwei-0.1.0-mac-arm64.dmg，在打开的窗口里把「紫微斗数」图标拖到「Applications」文件夹上。
  2. 第一次打开：在「启动台」或「访达 › 应用程序」里双击「紫微斗数」。系统会提示无法验证，按你的系统版本操作：

    macOS 15（Sequoia）及以上

    ③ 再弹出的窗口里点「仍要打开」，输入开机密码（或按指纹）。软件就会启动，以后直接双击即可。

    macOS 12 – 14

  3. 钥匙串提示：保存 AI 设置或升级新版本后，可能会弹出「紫微斗数想要使用钥匙串中的“紫微斗数 Safe Storage”」，输入开机密码后点「始终允许」。这是在读取加密保存的 API Key。
提示「已损坏，无法打开」？这通常是下载方式（例如通过聊天软件传输）给文件加了隔离标记。打开「终端」（启动台 › 其他 › 终端），粘贴下面这行后按回车，然后再打开软件：
xattr -dr com.apple.quarantine /Applications/紫微斗数.app

Windows 安装

  1. 下载：如果浏览器提示「通常不会下载此文件」或「可能有害」，点文件旁的「…」或箭头，选「保留」，再选「仍然保留」。
  2. 运行安装程序：双击 ziwei-0.1.0-win-x64-setup.exe。出现蓝色的「Windows 已保护你的电脑」时：
  3. 安装选项：选择安装位置（默认即可），点「安装」，完成后点「完成」。桌面和开始菜单会出现「紫微斗数」快捷方式。
  4. 杀毒软件拦截：360、火绒、电脑管家等可能提示风险，选择「信任」或「允许运行」，必要时把安装目录加入信任列表。

第一次使用

  1. 设置 AI：第一次启动会打开设置页。选 AI 服务商（推荐 DeepSeek），粘贴你的 API Key，点「测试连接」，成功后保存。也可以先点「先跳过，只排盘」，以后在顶栏「设置」里再填。
    • DeepSeek：到 platform.deepseek.com 注册并充值，在「API keys」里创建 Key。
    • 硅基流动：到 cloud.siliconflow.cn 注册，在「API 密钥」里创建 Key。
    AI 费用由你直接付给服务商，按用量计费。
  2. 书库：AI 解读默认查随软件附带的内置书库。想用自己的书，到「古籍库」页面的「书库」里新建书库、导入 PDF，并勾选它。
  3. 开始排盘：在首页填出生日期、时间和性别，排出命盘后就可以向 AI 提问。全部功能免费。

软件里顶栏的「帮助」页还有导入书、数据备份、升级卸载等说明。

遇到问题

  • 打开后一直显示「正在启动」或弹出「本地服务启动失败」：点「重试」；还不行就点「打开日志」，把日志附在问题反馈里。
  • AI 解读提示 Key 错误、余额不足或网络异常：检查 Key 是否复制完整、服务商账户余额、网络能否访问该服务商。
  • 卸载：Mac 把「应用程序」里的紫微斗数拖到废纸篓；Windows 在「设置 › 应用」里卸载。命盘等数据保留在本机，重装后还在。
